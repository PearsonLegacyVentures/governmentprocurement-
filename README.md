# Bahamas Government Procurement Intelligence

Internal-first procurement research and data-ingestion project for Pearson Legacy Ventures.

**Stage:** building and validating government-award data ingestion before presenting supplier rankings. The GitHub repository is public; never commit credentials or private commercial notes.

Primary sources: [Bahamas Public Procurement Department](https://mofvendors.gov.bs/) and [Bonfire](https://bahamas.bonfirehub.com/portal/?tab=pastOpportunities).

See `docs/ARCHITECTURE.md` for the staged implementation and `docs/DATA_POLICY.md` for evidence standards.
